Task Manager

Sistema Web de Gerenciamento de Tarefas

Python Flask SQLAlchemy SQLite HTML CSS PT / EN

Pedro Albuquerque

Visão Geral

Uma aplicação web para organizar tarefas do dia a dia, com foco em simplicidade, clareza visual e boa experiência de uso.

Organizar

Criar, editar e concluir tarefas com prioridade, prazo, tags e anexos.

Encontrar

Buscar, filtrar, ordenar e paginar para achar qualquer tarefa rápido.

Acompanhar

Dashboard, alertas de atraso e lembretes automatizados.

Funcionalidades

CRUD Completo

Criar, listar, editar e excluir tarefas.

Prioridade e Prazo

Alta / média / baixa, com alerta de atraso e vence hoje.

Concluir com 1 Clique

Alterna entre pendente e concluída.

Tags / Categorias

Etiquetas por tarefa e filtro por tag.

Anexos

Upload e download de arquivos na tarefa.

Busca, Filtros e Paginação

Por texto, status, prioridade e ordenação.

Recursos Avançados

API REST (JSON)

CRUD completo de tarefas para integrações.

Lembretes e E-mail

Avisos de tarefas atrasadas por SMTP (ou console).

Dashboard

Total, pendentes, concluídas e atrasadas.

Internacionalização

Interface em Português e Inglês (i18n próprio).

Anexos aceitos: pdf, png, jpg, gif, txt, doc, docx, zip — limite de 5 MB por arquivo.

Modelo de Dados

Entidade Campos principais Relação
Task title, description, priority, status, due_date, created_at, updated_at Centro do sistema
Tag name N:N com Task
Attachment filename, stored_name, created_at N:1 com Task
Propriedades calculadas: is_overdue (atrasada) e is_due_today (vence hoje).

Rotas e API

Rota Método Descrição
/ GET Página inicial
/tasks GET Lista, busca, filtros e paginação
/create GET POST Criar tarefa
/edit/<id> GET POST Editar tarefa
/toggle/<id> POST Concluir / reabrir
/reminders GET POST Enviar lembretes
/api/tasks GET POST PUT DELETE API REST de tarefas
Qualquer rota aceita ?lang=pt ou ?lang=en para trocar o idioma.
